# PlayGraf — Téléchargements

Ce dépôt héberge les installeurs Windows de **PlayGraf — Les aventures d'Aérion**, édité par **Neuratip**.

## Télécharger PlayGraf

👉 **[Télécharger la dernière version (Windows)](https://github.com/sebastienergo38-cpu/playgraf-releases/releases/latest/download/PlayGraf-Setup.exe)**

- Une **clé de licence** (reçue par e-mail après votre commande) et le **boîtier PlayGraf** sont nécessaires pour utiliser le logiciel.
- Les mises à jour sont proposées automatiquement au lancement du jeu.
- Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
